# Kul Shay — public pages

Support, privacy policy and terms of use for the «كل شي» (Kul Shay) app, served by GitHub Pages from `docs/`.

- https://hassanaldoosri-art.github.io/kulshay/
- https://hassanaldoosri-art.github.io/kulshay/support.html
- https://hassanaldoosri-art.github.io/kulshay/privacy.html
- https://hassanaldoosri-art.github.io/kulshay/terms.html

The pages are generated: edit `build.py`, then run `python build.py <support-email>` and commit `docs/`.
